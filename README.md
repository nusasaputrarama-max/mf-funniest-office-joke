Entry for the [make.fun](https://make.fun) bounty **"The Funniest Office Joke — Judged Head to Head"**
(competition `u-kevin-the-funniest-office-joke-judged-head-to-head-3dc3233c`).

## The entry

One original one-line joke about office life, written by the program in
[`main.ts`](main.ts):

> I told my calendar I needed focus time, so it booked me a meeting to discuss it.

## How it works

`main.ts` runs on Node 22 and writes the joke to `/output/entry.txt`
(1–200 characters, a single line), then prints it to stdout. It is fully
deterministic — the same bytes on every run.

```sh
node main.ts
```
